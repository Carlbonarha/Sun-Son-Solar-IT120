⚠️ COMMON ISSUES & FIXES:

"Can't login"
  → Clear browser cache (Ctrl+Shift+Delete)
  → Try Ctrl+F5 (hard refresh)
  → Check spelling of username/password

"Database not appearing in VS Code"
  → Restart VS Code
  → Make sure sun_son_solar.db is in project folder
  → Re-install SQLite extension

"CSS not loading (weird styling)"
  → Make sure styles.css is in same folder as HTML
  → Refresh browser (Ctrl+F5)

"Can't get GPS location"
  → Allow browser location permission
  → Some browsers need HTTPS (use Live Server)
  → GPS may not work in private/incognito mode

"Data disappears after closing browser"
  → Currently using localStorage (temporary storage)
  → This is normal for development
  → Will be replaced with permanent database
